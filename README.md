# Campus Shortest Route Finder

A menu-driven C program that finds the shortest route between different locations of a college campus using Dijkstra's Algorithm.

## Problem Statement

Develop a menu-driven C program to find the shortest route between different locations of a college campus.

## Features

- Enter campus locations
- Store the campus as a weighted graph
- Display adjacency matrix
- Select source location
- Find shortest distances
- Display shortest paths
- Display distance from source to all locations

## Algorithm

Dijkstra's Algorithm

## Data Structure

Weighted Adjacency Matrix

## Locations

- Main Gate
- Library
- Computer Department
- Laboratory
- Auditorium

## Complexity

Time Complexity: O(V²)

Space Complexity: O(V²)

## Language

C

## Output

The program displays the shortest distance and the actual shortest path from the selected source location to every other campus location.
